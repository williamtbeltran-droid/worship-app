Architecture & Database Technical Specification

Complete backend schema, real-time sync mechanism, and chord transposition logic for your engineering team.

PostgreSQL / Supabase DDL Schema 
-- 1. SONGS TABLE (Master library of chord charts in ChordPro format)
CREATE TABLE songs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(255) NOT NULL,
    artist VARCHAR(255),
    original_key VARCHAR(10) NOT NULL, -- e.g., 'C', 'G', 'Bb'
    default_bpm INT NOT NULL,
    time_signature VARCHAR(10) DEFAULT '4/4',
    chordpro_content TEXT NOT NULL, -- Raw ChordPro markup text
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. SETLISTS TABLE (Service lineups published by Worship Leaders)
CREATE TABLE setlists (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    service_date DATE NOT NULL,
    service_name VARCHAR(255) NOT NULL, -- e.g., 'Sunday Morning Service'
    worship_leader_id UUID REFERENCES users(id),
    status VARCHAR(50) DEFAULT 'published', -- 'draft', 'published'
    leader_notes TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. SETLIST_SONGS TABLE (Junction table that overrides default keys & defines order)
CREATE TABLE setlist_songs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    setlist_id UUID REFERENCES setlists(id) ON DELETE CASCADE,
    song_id UUID REFERENCES songs(id),
    song_order INT NOT NULL,
    target_key VARCHAR(10) NOT NULL, -- THE SINGLE SOURCE OF TRUTH KEY (e.g. 'E')
    capo_fret INT DEFAULT 0,
    custom_arrangements_map JSONB, -- e.g., ["Intro", "Verse 1", "Chorus", "Bridge", "Outro"]
    leader_dynamics_notes TEXT, -- e.g. "Start soft on Acoustic guitar"
    UNIQUE(setlist_id, song_order)
);

-- 4. STEMS_AUDIO TABLE (Audio backing tracks for missing rehearsal members)
CREATE TABLE stems_audio (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    song_id UUID REFERENCES songs(id) ON DELETE CASCADE,
    target_key VARCHAR(10) NOT NULL,
    click_guide_url TEXT,
    vocals_url TEXT,
    keys_pad_url TEXT,
    guitars_url TEXT,
    rhythm_url TEXT
);

Dynamic Key Transposition Logic (JS)

Chords are calculated modulo 12 based on the chromatic scale array. When the worship leader updates the `target_key`, the client recalculates distance in semitones:

distance = (KEYS.indexOf(targetKey) - KEYS.indexOf(originalKey) + 12) % 12;

Real-time Websocket/Supabase Sync

Subscribe all musician tablets to setlist updates via Supabase Realtime Postgres Changes:

supabase.channel('setlist-changes')
 .on('postgres_changes', { event: 'UPDATE', table: 'setlist_songs' }, payload => {
   updateLiveChordChart(payload.new.target_key);
 }).subscribe();
